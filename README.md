# Hereditary Cancer Ecosystem Map

An interactive map of the organisations that make up the hereditary cancer ecosystem, built on BRCA1
and BRCA2 as the proof of concept. The framework is not specific to those two genes and is intended
to hold for any germline pathogenic variant.

## Structure

Seven tiers, 34 rows. Each tier asks one question, and each row inside it is a membership test an
organisation either passes or fails.

| Tier | Rows | The question it asks |
|---|---|---|
| Capital | 6 | Who decided this was worth funding, and why? |
| Knowledge | 5 | What do we understand, and how do we find it in people? |
| Enabling Technology | 3 | The picks and shovels beneath every tier. |
| Intervention | 5 | How does knowledge become clinical action? |
| Gatekeepers and Payers | 6 | Who controls whether it reaches people? |
| Care Access | 7 | How does an individual carrier actually get there? |
| Frontier | 2 | What does this biology tell us about something larger? |

As of 29 August 2026 the map holds 253 organisation records and renders 271 placements across 247
organisations. An organisation appears in more than one row where it does more than one thing.

Filter by gene or by disease. Click an organisation for its profile.

## How a placement is evidenced

Every placement carries the argument for it, an evidence link to the organisation's own page or to a
named public document, and an argument against itself stating what would overturn the placement.

Two evidence states, and neither means verified:

**Cited.** A named document states it: a ClinicalTrials.gov registration field, a PubMed author
list, or a page on the organisation's own website.

**Proposed.** Inferred rather than stated, for example two organisations appearing together on a
large multi-institution paper.

Verified is a third state and requires a person to open the source and confirm it.

**No connection or placement on this map was generated by a language model.**

## Not yet published

The relationship layer, which types the connections between organisations, holds 457 edges in the
source workbook and is not rendered here. It is withheld until every edge carries a source class
and a retrieval date, which 11 of the 457 currently do.

## Technical

One self-contained `index.html`. No server, no build step, no dependencies. Rebuilt from a source
workbook, so the published file is generated rather than edited.
