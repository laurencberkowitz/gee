# GEE: BRCA Edition

GEE: BRCA Edition is a curated ontology of the BRCA1 and BRCA2 ecosystem, published as a public, evidenced knowledge base and directory.

Live at https://laurencberkowitz.github.io/gee/ and https://laurenberkowitz.co/map

Public beta. Corrections and additions go through the GrowGEE button on the page.
